# 网格系统规范

适用于所有物料的排版间距与宽度分配，不限于展板、易拉宝、KV、手机海报这类固定像素画布物料——PPT、官网、社媒图片、视频封面、公众号封面等也统一按本文件的模数单位来给间距和宽度定节奏，不要每个物料各自发明一套间距逻辑。印刷物料需先按各自的尺寸换算规则转成像素画布，再套用本文件。目的是让元素之间的间距有统一节奏，而不是每个间距都凭感觉给一个不相关的百分比——那样即使单看每一处都"差不多合适"，整体也会显得没有章法。

## 优先级规则（先看这条，避免和其他规范打架）

**功能性尺寸优先于网格系统**。标题最小/最大字号（`typography-fit-to-canvas.md`）、二维码最小边长（`QR-code.md`）这类由独立公式算出来的尺寸，不能为了凑网格列宽或模数倍数而压缩变形。网格系统只管两件事：**元素之间的留白间距节奏**、**纯装饰/留白/多列并排元素的宽度和位置**。

**物料自定义边距优先于网格默认边距**。如果某个物料文件已经写明了自己的安全边距（比如易拉宝的 10-12%、手机海报的专属安全框），列网格的可用宽度按该物料文件的边距计算；本文件下方的默认边距公式只在物料文件没有特别说明时兜底使用。**但无论边距来自物料专属规则还是本文件默认公式，都不能低于下方"最小边距下限"——这是硬性下限，任何来源的边距都要先过这一关，物料专属边距如果算出来比下限还窄，按下限执行。**

## 两级模数（管所有尺寸的计算基准）

共享视觉系统只有一个根数字：**原子尺寸 = 2px**。字号系统（`design-foundation.md` 1.2 节）和本文件的间距系统都从这一个数字反推，但两者使用不同的工作颗粒度：

| 系统 | 工作单位 | 用途 |
|---|---|---|
| 字号 | 原子尺寸本身（2px）的整数倍 | 字号之间差异小，需要精细刻度（如 14、16、18、20、22、28） |
| 布局（间距 / 边距 / 列宽） | **布局模数 = 原子尺寸 × 4 = 8px** 的整数倍 | 间距如果也精细到每 2px 一档，画面节奏会显得琐碎，用更粗的台阶保持克制感 |

两者共享同一个根数字（2），只是常用挡位不同——字号和间距永远可以互相换算，不会出现"两套互不相关的系统"。本文件下方所有计算，均以**布局模数（8px）**为单位。

PPT 适配层为避免和导出图片像素混淆，将本文件计算出的数值一一映射为 LU：`1px（本文件逻辑数值）→ 1 LU`。例如公共网格的 8px gutter 在 PPT 中写作 8 LU，再按 `references/materials/ppt/components.md` 的 `lu()` 函数转换为英寸。不得把公共 px 或 PPT LU 直接作为 PptxGenJS 坐标传入。

## 多语版式的纵向留白

同一份固定版式需要生成多语版本时，禁止使用 `justify-content: space-between` 或 `space-around` 分配纵向留白。它们计算出的间隔可能是任意小数，不符合 8px 布局模数；间隔还会随内容长度改变，而中文通常比同义英文短 30–40%，同一份 CSS 无法维持一致节奏。

- 组内使用固定的 8px 模数 `gap`，间距取能容纳最长语种的最大模数值。
- 整组使用 `justify-content: center` 或 `margin: auto` 定位，将富余留白集中到组的两端。

## 定高版面的富余留白

折页、展板、易拉宝等高度固定的版面排完内容后，必须由设计者明确指定富余留白的位置，禁止交给浏览器平摊，并列的同级条目也不例外。

- 组内间距一律使用固定模数 `gap`，并按最长语种确定能容纳内容的最大模数值。
- 使用 `margin-top: auto` 或让指定容器承担 `flex: 1`，将富余留白集中到一处；通常放在当前列底部、页脚色块上方。底部保留一段空白是正常结果，不要为了“排满”而把条目间距拉大。
- 网格禁止用 `grid-auto-rows: 1fr` 平摊行高，否则视觉行距会变成 `row-gap` 与单元格内富余高度之和。使用 `grid-auto-rows: min-content`、`align-content: start` 和固定模数 `row-gap`。
- 同一份物料的各栏尽量共用同一个条目间距；只有条目最多、按共用间距无法容纳的栏才降一档，并在源码注释中说明原因。

## 边距计算规则（管左右 / 上下留白）

**第一步：参考边距**
```
参考边距 = 画布宽度 × 6%，就近取整到布局模数（8px）的整数倍
```

**第二步：最小边距下限（硬性下限，避免边距过小）**
```
最小边距 = max(绝对下限 32px, 画布宽度 × 4%)，向上取整到布局模数（8px）的整数倍
```
绝对下限 32px（= 布局模数 × 4）保证即使是很窄的画布，边距也不会小到贴边；相对下限（4%）保证大尺寸物料的边距不会显得比例失调地窄。

**第三步：取两者中更大的值作为实际边距**
```
实际边距 = max(参考边距, 最小边距)
```
画布越窄，"参考边距"算出来的值往往会被"最小边距"顶住，此时按最小边距执行；画布越宽，两者通常一致或参考边距更大。

示例：
| 画布宽度 | 参考边距（6%取整） | 最小边距下限 | 实际边距 |
|---|---|---|---|
| 1080px | 64px | 48px | 64px |
| 750px | 48px | 32px | 48px |
| 375px | 24px | 32px | 32px（被最小边距顶住） |

## 列网格（管多列并排内容的宽度和位置）

**列数按画布宽度分级，不强行用同一个列数套所有物料**：

| 画布宽度 | 列数 | 适用物料举例 |
|---|---|---|
| ≥ 800px（宽幅/复杂版式） | 12 列 | PPT、官网、展板、KV、社媒方图 |
| < 800px（窄幅/简单版式） | 6 列 | 手机海报、竖版视频、部分小尺寸封面图 |

列数分级的原因：窄画布如果也强行切成 12 份，每列会薄到失去实际意义（没人会把一张手机海报当成 12 列在用），列数越少，每列越有分量，也更贴近窄幅物料"通常只需要一次二分或三分"的实际排版需求。列间距（gutter）统一为布局模数 × 1 = 8px，不随列数变化。

**列宽计算（列宽必须是布局模数的整数倍，边距负责吸收无法整除的零头，不反过来让列宽出现小数）**：
```
可用宽度候选 = 画布宽度 − 2×实际边距
列宽 = floor((可用宽度候选 − (列数−1)×8) ÷ 列数)，再向下取整到 8px 的整数倍
零头 = 可用宽度候选 − (列数×列宽 + (列数−1)×8)
零头平分计入左右边距（每侧 += 零头 ÷ 2，不要求是 8px 的整数倍——边距本来就是吸收误差的地方）
```

示例（1080px 画布，实际边距 64px，12 列）：
```
可用宽度候选 = 1080 − 128 = 952px
列宽初值 = (952 − 11×8) ÷ 12 = (952 − 88) ÷ 12 = 72px（已经是 8 的整数倍，零头为 0，边距不需要再调整）
```

示例（375px 画布，实际边距 32px，6 列）：
```
可用宽度候选 = 375 − 64 = 311px
列宽初值 = (311 − 5×8) ÷ 6 = (311 − 40) ÷ 6 ≈ 45.17 → 向下取整到 8 的倍数 → 40px
零头 = 311 − (6×40 + 40) = 311 − 280 = 31px
零头平分：每侧边距 += 15.5px，最终左右边距约为 47-48px（取整到像素即可，不必是 8 的倍数）
```

不同画布宽度的实际边距、列宽都需要按自己的画布重新算一遍，不能跨物料直接套用像素值。

多列并排的内容（比如左文右图、多图网格、信息卡片横排）按"跨几列"分配宽度，例如某个元素跨 3 列 = 3×列宽 + 2×8（列间距）。单一居中元素（比如展板正中间的 Logo/标题/二维码）不强制对齐到列边界，只需要整体居中，垂直间距按布局模数（8px 的整数倍）来就够了。

## 图片裁切规则（管素材图片的宽高怎么定）

物料中的视觉先按功能分类，再决定完整显示或裁切；不能只因为已经画出一个固定容器，就裁掉有用信息。

- **信息型视觉**：产品截图、界面、图表、表格、流程图和示意图必须完整显示。按原始比例在网格区块内缩放；比例严重不匹配时调整区块、切换布局或拆页，不能裁掉信息。
- **表现型视觉**：照片、人物、场景图和装饰性插画可以按目标网格区块裁切，但必须保护主体和关键内容。
- **多图组**：同组视觉使用同一种适配方式。表现型图片统一裁成单元格比例；信息型图片需要完整显示时，先选择能容纳共同纵横比的网格，无法成立就改用其他布局或拆页，不能用拉伸或随意裁切强行统一。
- **统一性**：同类物料一旦确定表现型视觉的统一裁切比例，后续保持一致，不跟着素材原始比例随意变化。
- **禁止变形**：无论完整显示还是裁切，都不得拉伸、压扁或同时写死不匹配的宽高。

## 封面类物料的横向内容分区（图文左右分区、多元素并排）

单图背景 + 文字/Logo 叠加的封面类物料（文章封面、公众号封面、小红书/抖音封面、手机海报、展位背景板等），如果构图需要切成"图片区/文字区"或多个元素左右并排，分区边界也必须落在列网格的列边界上，不能用"右侧 40%""左侧 60%"这种不对齐网格、凭感觉给的比例。

计算方法：
1. 按本文件上方公式，用该物料的画布宽度（或其专属安全区宽度）确定列数（12 或 6）、算出实际边距和列宽；
2. 给每个分区分配整数列跨度（比如 12 列物料里文字区 5 列、图片区 7 列，两者之和 = 12；6 列物料里文字区 2 列、图片区 4 列，两者之和 = 6）；
3. 分区之间的间隙用一个列间距（gutter）即可，不用再叠加额外的安全距离。

各物料的具体列跨度分配和换算结果见各自文件里的"横向网格"小节；每个物料按自己的画布宽度重新计算列宽，不能跨物料直接套用像素值（与边距规则一致）。

## 元素对齐

- 同一个文字块内的多行内容（标题换行、说明文字换行）需保持一致对齐方向（居中/左/右均可，按物料实际需要选择）。不要出现"第一行居中、第二行因为文字框宽度不同而偏一边"的情况——用 `text-align` 显式声明（`center`/`left`/`right` 按实际方向选取），不要只依赖父容器的 `align-items: center`（那只对齐整个文字块，不管块内多行文字彼此的对齐关系）。
- "文字块"的定义：仅指同一个语义元素（一段标题/一段说明文案）因换行产生的多行，不包括画面里彼此独立的其他元素（logo、标签、时间、其他文案块等）。
