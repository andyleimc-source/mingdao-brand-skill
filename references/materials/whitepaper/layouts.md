# 白皮书布局与长文档排版规范

本文件定义明道云与 Nocoly 共用的白皮书页面骨架、排版节奏、分页行为和 PDF 验收规则。字体、语言映射与 Logo 资产从当前品牌配置读取；标题层级与章节编号执行 `references/common/document-heading-numbering.md`；色彩、视觉必要性和同组配色继续执行 `references/common/design-foundation.md`，网格根模数执行 `references/common/grid-system.md`，Logo 尺寸和安全区执行 `references/common/logo.md`。

首版默认值提取自已经完成 PDF 验收的明道云 HAP GB/T 46900 合规白皮书。该样本只用于建立初始参数，不代表所有白皮书都必须采用合规报告的章节数量、三列表格或证据附录。

首版不建立白皮书组件库。正文、列表、表格、图片和注释先作为长文档基础结构使用；某种复合结构在不同主题白皮书中重复出现并验证有效后，再建立 `components.md`。

## 生成前封面颜色确认

开始排版前执行 `references/common/generation-checklist-common.md`。用户没有指定封面颜色时，AI 先按 `references/common/design-foundation.md` 1.1 节推荐一种颜色并说明理由，再提供品牌蓝 `#1677FF`、云灰 `#E0E5EC`、墨蓝 `#082C5E`、纯白 `#FFFFFF` 四个选项，等待用户确认后再生成 PDF。只确认封面一次；普通内容页默认白色，不逐页询问背景色。用户确认颜色后，Logo 标准版或反白版按 `references/common/logo.md` 自动匹配。

## 1. 规则强度

- **硬规则**：必须满足；不能为了减少页数或填满页面而突破。
- **默认值**：没有明确内容理由时直接采用的具体数值，不是可忽略的“建议”。
- **允许调整范围**：内容、语言、字体或页面角色变化时可以使用；偏离默认值时记录原因，并重新渲染整份 PDF。

先使用默认值完成排版。只有真实内容无法成立时，才在允许范围内调整；仍无法成立时切换页面结构、拆表或拆页，不继续压缩字号和必要留白。

## 2. 生成与验收对象

- 最终视觉验收对象是 PDF。HTML、DOCX 或其他源文件只是中间实现，不能代替 PDF 验收。
- 默认交付 A4 PDF；用户需要可编辑文档时可以同时交付 DOCX，但必须由同一内容结构生成，并分别检查字体、分页和表格。
- 每次影响字号、间距、页边距、表格或分页的修改，都重新生成并渲染整份 PDF。
- 用户确认的 PDF 必须与通过最终验收的文件相同；确认后不得另行生成未经检查的版本。

## 3. 单位与页面系统

### 3.1 单位

- 纸张和页边距使用 `mm`；字号、行距、段前段后和细线使用 `pt`。
- 不在白皮书规范中使用 `px` 作为最终单位，也不把浏览器像素直接传给 DOCX 或 PDF 渲染器。
- 白皮书的主要版面间距使用 6pt 模数，对应共享网格的 8px 逻辑模数；标题与段落之间的精细排版允许使用 3pt 半模数。3pt 半模数只用于垂直文字节奏，不用于随意改变页边距、列宽或图片尺寸。

### 3.2 页面

| 项目 | 默认值 | 允许调整 |
|---|---:|---:|
| 纸张 | A4 纵向，210 × 297mm | 宽表或横向图表无法合理拆分时才使用 A4 横向 |
| 正文页边距 | 四边 18mm | 16–22mm；不得为了少一页缩到 16mm 以下 |
| 正文可用宽度 | 174mm | 随左右页边距重新计算 |
| 页眉位置 | 距页面顶边约 7mm | 6–9mm |
| 页脚位置 | 距页面底边约 5mm | 5–8mm |

- 封面默认不显示运行页眉、页脚和页码。
- 内页页眉、页脚位于正文内容区之外，但必须留在纸张安全范围内。
- 默认使用单栏正文。确需并排内容时，按 6 栏窄幅网格计算；栏间距默认 3mm，一级区域必须跨整数栏。
- 表格列宽可以按真实字段语义分配，不要求每一列等宽；整张表仍须对齐正文内容区。

## 4. 页面角色

页面角色用于选择骨架，不限制白皮书必须包含全部页面。

### 4.1 封面

- 只建立一个视觉重心。
- 封面使用生成前已经由用户确认的颜色；不得在排版阶段静默改用其他主背景色。
- 默认内容为 Logo、主标题、副标题、必要元数据和免责声明；没有实际内容的字段不占位。
- Logo 默认只在封面承担明确品牌识别，保持官方比例和安全区。
- 标题区与元数据区分离，避免把发布日期、密级、版本等辅助信息提升为第二视觉中心。

### 4.2 目录

- 目录可以独占一页或自然跨页，不为了塞进一页缩小字体。
- 目录只表达章节层级和定位信息；装饰线仅在帮助行扫描时使用。
- 是否显示章节编号按 `references/common/document-heading-numbering.md` 判断；无编号模式只排列标题名称与页码，编号模式按“编号 / 标题 / 页码”建立稳定列关系，同级条目保持一致。

### 4.3 前言与其他前置内容

- 从新页开始，沿用正文内容区。
- 使用正文层级组织编制目的、适用范围和阅读说明，不另造封面式构图。

### 4.4 章节起始页

- 每章从新页开始。
- 章节标识、章节标题和概述可以出现在同一页；不强制为每章增加独立的纯过渡页。
- 章节变化本身不构成换色理由。

### 4.5 普通内容页

- 默认白色背景、单栏连续阅读。
- 根据真实内容使用标题、段落、列表、表格、图片或图表；不要求固定“标题＋说明＋要点”结构。
- 页面中不为了填满底部留白而添加内容或装饰。

### 4.6 附录与证据页

- 沿用正文页边距、标题层级和页眉页脚，不另建一套视觉语言。
- 编号、说明和证据状态保持稳定顺序。原始证据缺失时明确标注，不生成替代截图或虚构证明材料。

### 4.7 封底

- 封底为可选页面，不是白皮书必备结构。
- 只有存在联系信息、版权、下载入口或明确 CTA 时才生成；不得仅为“完整感”增加空封底。

## 5. 字体层级与垂直节奏

字体家族、字重名称和缺失字体处理只从当前品牌配置读取。下表定义共用的字号与节奏。

### 5.1 字号

| 层级 | 默认值 | 允许调整 | 默认行高 |
|---|---:|---:|---:|
| 封面主标题 | 36pt | 30–42pt | 1.2 |
| 封面副标题 | 15pt | 14–18pt | 1.5 |
| 章节标题 | 21pt | 20–24pt | 1.2 |
| 小节标题（二级） | 15pt | 14–17pt | 1.2 |
| 小标题（三级） | 12pt | 11–13pt | 1.5 |
| 正文 | 10.5pt | 10–11pt | 1.5 |
| 表格、注释、图注 | 7.5pt | 7.5–9pt | 1.5 |
| 运行页眉页脚 | 7.5pt | 7.5–8pt | 1.5 |

- 表格、注释和页眉页脚不得低于正文的 0.7 倍。
- 同一普通内容页尽量不超过四种字号；先用字重、留白和对齐建立层级。
- 不得通过缩小正文字号解决分页问题。

### 5.2 段落与标题间距

| 关系 | 默认值 | 允许调整 |
|---|---:|---:|
| 正文段后 | 12pt | 9–15pt |
| 二级标题段前 | 27pt | 24–30pt |
| 二级标题段后 | 9pt | 6–12pt |
| 三级标题段前 | 18pt | 15–21pt |
| 三级标题段后 | 9pt | 6–9pt |
| 引导段段前 / 段后 | 12pt / 18pt | 按 3pt 递增或递减 |
| 表格段前 / 段后 | 12pt / 18pt | 按上下文在 9–24pt 内调整 |

硬规则：

- 同级标题的间距保持一致。
- 标题上方留白必须大于下方留白，使标题明确归属于后续内容。
- 标题成为自然分页后的首个正文元素时，取消完整段前距；页首保留 0–9pt 即可。
- 标题不能孤立在页尾，必须与至少一段正文、一个列表项或后续结构的首行同页。
- 调整标题顶部间距时优先重新分配顶部和底部间距；总占用高度没有必要增加时，不通过整体增高造成文档无意义增页。

## 6. 内容流与分页

### 6.1 强制分页

- 封面和目录结束后换页。
- 前言、正文第一章和每个后续章节从新页开始。
- 附录从新页开始。
- 普通小节不默认强制换页。

### 6.2 连续阅读

- 正文段落至少保留 3 行孤行与寡行控制。
- 二级、三级标题启用“与下段同页”。
- 列表项尽量保持完整；单个列表项过长时允许自然跨页，但不得只把项目符号或编号留在上一页。
- 图注与对应图片、表题与对应表格保持同页。
- 不把一个短收尾段单独留在章节换页前的疏空页面。出现这种情况时，先在允许范围内重分配前文间距或调整表格分页，不缩小字体。

### 6.3 页数变化

- 页数变化本身不是失败；内容增减、字体切换和合理留白都可能改变页数。
- 只要修改间距后页数变化，就检查新增页出现在哪里以及为什么出现。
- 新增页如果只包含孤立标题、单行收尾、异常表尾或可避免的大面积空白，则判定为分页退化，必须修正。

## 7. 表格

### 7.1 默认样式

| 项目 | 默认值 |
|---|---:|
| 表格宽度 | 正文内容区 100% |
| 字号 | 7.5pt |
| 行高 | 1.55 |
| 单元格内边距 | 6pt |
| 表格段前 / 段后 | 12pt / 18pt |
| 边框 | 0.5–0.75pt |
| 表头背景 | 品牌云灰 `#E0E5EC` |

- 表头背景固定使用品牌云灰 `#E0E5EC`，并使用清晰字重；正文单元格保持中性背景。
- 颜色只承担表头、状态或真实对比功能，不按行、列或单元序号轮换品牌色。
- 同一类表格保持表头、内边距、边框和字段顺序一致。

### 7.2 列宽

- 先按字段的信息密度和阅读任务分配列宽，不默认等宽。
- 三列“要求 / 对应能力 / 证据”关系可以使用约 `31% / 48% / 21%` 作为初始值；其他三列表格不得机械套用。
- 文本字段优先获得宽度，短状态、编号和日期字段只保留满足可读性的最小宽度。
- 宽表在缩小文字前依次尝试：调整列宽、精简重复表头、拆成两张关联表、使用横向页面。

### 7.3 跨页

- 跨页表格重复表头。
- 默认禁止拆分单行。
- 单行内容高于可用页面时，将内容按语义拆成连续行或子表，并标注“续”；不得让文字裁切或溢出。
- 表格前的标题或说明必须与表头及首行同页。

## 8. 图片、图表与视觉元素

- 信息型视觉必须完整显示，不能裁掉界面、标签、图例或数据。
- 表现型照片和插画可以裁切，但必须保护主体；同组图片采用一致适配方式。
- 图片和图表使用原始比例；比例不适配时调整版式、改为横向页面或拆页，禁止拉伸。
- 图注紧邻对应视觉，默认使用注释层级。
- 线、色块、图标、卡片背景和边框只在去掉后会损害理解时使用，并采用完成该功能所需的最小形式。
- 白皮书不因主题涉及“技术、连接、智能”而添加渐变、光效、抽象节点或装饰性图形。

## 9. 品牌在长文档中的使用

- 整份白皮书默认使用同一个主导色；章节变化不自动切换颜色。
- 普通内容页默认使用白色背景，正文使用功能文字色，标题和局部标识使用当前主导品牌色。
- 表格组、列表组和证据组保持组内配色一致；颜色分组、异化和两列对比继续执行共享设计基础中的语义与面积限制。
- 封面默认显示官方 Logo；普通内页默认不重复放置 Logo，以页眉文字、色彩和排版维持品牌识别。
- 用户要求内页 Logo 时，整份文件使用同一固定位置和级别，并弱化处理，不与内容争夺视觉重心。
- 页脚内容由用户或文档事实决定；没有版权、密级、日期或项目名称等真实内容时不虚构。

## 10. PDF 验收

### 10.1 文件与内容

- PDF 可正常打开、未加密、纸张方向与尺寸一致。
- 页数、目录、章节、附录、页码和页脚对应正确。
- 从 PDF 提取文本，与源内容检查标题、正文、表格和关键字段是否缺失；不得只依赖截图目检。
- 检查字体实际可用且没有缺字、方框、乱码或静默替换；字体缺失处理执行当前品牌配置。

### 10.2 逐页视觉检查

将最终 PDF 的每一页渲染为图片并逐页检查：

- 无裁切、重叠、溢出、空白页和异常黑块。
- 标题层级、标题顶部间距、正文行距和表格密度一致。
- 无孤立页尾标题、单行章节收尾、异常表尾或可以避免的疏空页。
- 表头重复正确，表格行没有被错误截断。
- 页眉、页脚和页码位置稳定；封面不误显示运行页眉页脚。
- 图片、图表和 Logo 比例正确且清晰。
- 封面背景色与生成前用户确认的选项一致；缺少确认记录或静默换色均不通过。
- 每页只有一个明确视觉重心，同组配色一致，整份文件没有按章节或页面装饰性轮换品牌色。

### 10.3 修改循环

任一项不通过时：

1. 回到生成源修正，不直接在最终 PDF 上做不可追溯的手工覆盖。
2. 重新生成完整 PDF。
3. 重新执行文件检查、文本检查和全部页面视觉检查。
4. 只向用户展示最后一轮通过验收的 PDF。
