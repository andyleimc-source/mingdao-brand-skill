# 展位背景板（KV）

## 生成前内容关卡

开始设计前执行 `references/common/generation-checklist-common.md` 的软确认流程。

- **KV 专属必要事实**：展位实际尺寸。尺寸缺失且无法从供应商模板或上下文查明时，命中“关键事实缺失”，只询问尺寸并推荐常见的 3×2.5m / 6×3m 规格供核对。
- 内容去重和信息层级按通用内容关卡自动判断；背景色未指定时由 AI 推荐并提供四色选项，取得用户确认后再生成。Logo 版本根据确认后的背景自动匹配。

## 规格

- **常用尺寸**：3×2.5m / 6×3m（按展位实际确认）
- **横向网格**：本物料没有固定像素画布（尺寸按展位实际确认），需要先按 `references/materials/print/print-exhibition-board.md` 的"尺寸换算规则"（横版画布宽度固定 1080px，高度按实际宽高比换算）把米数换算成像素画布，再按 `references/common/grid-system.md` 十二列网格公式计算横向分区列宽，不能跳过换算直接套用列宽公式。
- **色彩模式**：CMYK，分辨率 72dpi（大尺寸喷绘）
- **交付格式**：AI 矢量优先；含出血 3cm
- 背景用品牌三色中的一色或纯白满版 + 网格化版式为主。AI 按内容和场合参考 `references/common/design-foundation.md` 1.1 节提出推荐和四色选项，等待用户确认后采用；不使用装饰性插图、渐变光效、连接线/节点插画——这类元素属于 `references/common/design-foundation.md` 0.1 节明确禁止的"为表达抽象概念而添加的装饰性视觉元素"。
