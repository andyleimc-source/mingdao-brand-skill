# PPT 母版规范

本文件定义 PPT 中不随具体内容布局变化的固定页面框架。明道云与 Nocoly 共用同一套母版几何结构；先读取 `references/common/design-foundation.md`，再按品牌路由读取 `references/brands/mingdao.md` 或 `references/brands/nocoly.md`，以取得对应 Logo、字体和语言规则。

一张页面由五层组成：

```text
结构母版 + 背景样式 + 内容布局 + 页内组件 + 当前品牌配置
```

- 本文件管理 Logo、标题预留区、内容安全区、页码和页脚等固定结构；背景样式是与结构母版正交的页面视觉属性。
- `layouts.md` 管理内容安全区内的一级区域关系。
- `references/common/component-system.md` 管理组件语义，`components.md` 管理组件在 PPT 中的 LU 几何配方。
- Logo 尺寸、安全区和背景适配继续以 `references/common/logo.md` 及当前品牌配置为准，本文件只定义 PPT 中的锚点和使用级别。

## 1. 母版选择原则

### 1.1 整份 PPT 先确定默认母版策略

- 普通内容页先选定一个默认内容页母版，默认使用弱品牌变体。
- 需要独立传播、明确强化品牌归属或承载关键结论的普通内容页，才改用标准品牌变体。
- 封面、章节过渡和结束页按固定结构切换母版；不得为了制造节奏在相邻普通内容页之间轮换 Logo 强弱或背景模式。
- 新的母版变化必须由页面职责、信息可读性或传播目的驱动，不能以“丰富画面”为理由。
- 背景颜色、图片或视频本身不构成新的结构母版；只有 Logo、标题、页脚、页码或内容排除区等固定结构发生变化时，才建立布局变体。

### 1.2 固定框架不计入内容布局

页面标题、Logo、页码和页脚属于母版框架，不计入 `layouts.md` 的内容分区：

- “单一区域”指母版框架之外只有一个主要内容区域。
- “上下分区”必须表达两个真实内容区域，不能因为页面顶部有标题就判定为上下分区。
- 内容布局不得覆盖 Logo 排除区、页码或页脚。

### 1.3 结构布局与背景样式正交

结构布局只记录固定对象和内容区；背景样式单独记录并在页面创建时应用。不得把背景色写入母版身份，也不得因为背景变化复制一套内容区。

结构布局名称采用：

```text
<家族>.<页面状态>.<固定对象状态>
```

例如：

```text
BrandFocus.Cover.WithLogo
BrandFocus.End.NoLogo
Content.WithTitle
Content.NoTitle.TenColumns
Section.NoLogo
```

品牌、Logo 级别和背景另行记录，例如：

```text
brand = Mingdao
logoLevel = Weak
backgroundStyle = Brand.Blue
```

明道云与 Nocoly 复用同一结构布局 ID。生成脚本只实例化本次演示实际使用的固定对象组合，不预先生成背景色与结构布局的笛卡尔积。

## 2. 1920×1080 LU 母版坐标

PPT 使用 `workflow.md` 定义的 `1920 × 1080 LU` 整数逻辑画布。横向网格沿用 `grid-system.md` 的计算结果并一一映射为 LU：左右边距 148 LU、12 列、列宽 128 LU、gutter 8 LU。纵向参考边距为 112 LU。

| 区域或锚点 | 逻辑坐标 | 说明 |
|---|---|---|
| 画布中心轴 | `x = 960` | 品牌焦点母版的水平基准 |
| 内容水平安全区 | `x = 148–1772` | 宽 1624 LU，对应完整 12 栏 |
| 常规纵向安全区 | `y = 112–968` | 上下各保留 112 LU |
| 无顶部或底部固定对象的完整内容区 | `x = 148, y = 112, w = 1624, h = 856` | Cover 之外的无 Logo 品牌焦点页、章节过渡页等使用 |
| 右上角 Logo | 右边缘 `x = 1772`，顶部 `y = 112` | 宽度按 `logo.md` 计算；1920 LU 画布基准宽度为 184 LU |
| 页面标题区 | `x = 148, y = 112, w = 1352, h = 96` | 跨前 10 栏；字体与层级见当前品牌配置和 `components.md` |
| 有顶部固定对象的内容区 | `x = 148, y = 240, w = 1624, h = 728` | 顶部 Logo 或标题排除区后保留必要间距 |
| 无标题上部扩展区 | `x = 148, y = 112, w = 1352` | 仅前 10 栏可向上扩展 |
| 无标题全宽内容区 | `x = 148, y = 240, w = 1624, h = 728` | 右侧两栏从此高度开始可用 |
| 页脚基线区 | `x = 148, y = 1016, h = 24` | 仅整份 PPT 启用页脚时使用 |
| 页码区 | `x = 1708, y = 1016, w = 64, h = 24` | 右对齐，仅普通内容页使用 |

右上角 Logo 的基础宽度在明道云与 Nocoly 中保持一致，高度按各自官方 SVG 的真实长宽比自动换算，禁止同时写死宽高。为兼容较高的明道云完整版 Logo，无标题状态下将右侧最后两栏的 `y = 112–232` 视为 Logo 排除区；内容从 `y = 240` 起才可使用完整 12 栏。

这些坐标是 `1920 × 1080 LU` 画布的结构锚点，不是所有内容组件的固定坐标。每个具体结构布局必须明确返回自己的 `contentArea`；不能因为背景相同、同属品牌焦点页或代码复用方便而借用其他布局的内容区。内容布局仍须按 `layouts.md` 选择网格跨度，并按 `components.md` 重新计算有效内容框和组件高度。

## 3. 三类母版家族

### 3.1 品牌焦点母版

**用途标签**：封面、结束页、纯品牌声明页。

**固定框架**

- Cover 默认保留 Logo；End 的 Logo 默认关闭，只有用户明确需要时才显示。
- Logo 显示时进入画布中心轴，并按本节的 Standard / Focus 规则选择锚点。
- 不显示页码和页脚。
- 不预设普通内容页的右上角 Logo。
- 背景样式在结构布局之外单独确定；Logo 按最终背景使用标准版或反白版，但背景不得改变内容区。

**有限变体**

| 结构布局 | Logo 规则 | `contentArea` |
|---|---|---|
| `BrandFocus.Cover.WithLogo` | 默认显示 Standard Logo；水平居中，顶部 `y = 112`，基准宽度 `184 LU` | `x = 148, y = 240, w = 1624, h = 728` |
| `BrandFocus.End.NoLogo` | End 默认状态，不显示 Logo | `x = 148, y = 112, w = 1624, h = 856` |
| `BrandFocus.End.WithLogo` | 用户要求显示时与 Cover 使用相同 Standard 尺寸和顶部锚点 | `x = 148, y = 240, w = 1624, h = 728` |
| `BrandFocus.LogoOnly` | 页面除 Logo 外没有其他主要内容时，允许使用 Focus Logo；水平、垂直居中，基准宽度 `304 LU` | 无主内容区；不再添加标题、结束语或联系方式 |

- 封面或封底存在标题、结束语、联系方式等主要内容时，Logo 属于母版顶部品牌标识，不参与主内容组的垂直居中计算。
- End 未显示 Logo 不属于品牌缺失；AI 不得因为页面留白较多而自行添加。
- Cover / End 的主内容组先按真实内容测量高度，再在当前结构布局返回的 `contentArea` 内垂直居中；禁止分别写死标题、说明或联系方式的页面级 `y` 坐标。
- 封面主标题与封底主要结束语使用同一 `BrandFocus.Primary` 语义字号角色，当前默认值为 `48 pt`。只有真实文案测量后无法在安全宽度内容纳时，才按同一离散字号阶梯降级；不得因为页面用途是 End 就固定改用更小字号。
- 联系方式、短说明等辅助信息使用其自身辅助层级，与主要语句共同组成一个待测量的内容组，不参与决定主要语句是否降级。
- Logo 居中指进入页面中心轴，不要求 Logo 和主内容占据同一个几何中心点。若主视觉需要满版出血，Logo 仍需保持安全区和足够对比度。

**兼容布局**：单一区域、全幅视觉叠加内容。

### 3.2 章节过渡母版

**用途标签**：章节分隔、叙事转场、阶段切换。

**固定框架**

- 默认不显示 Logo。
- 不显示页码和页脚。
- 使用 `Section.NoLogo`，`contentArea = x 148, y 112, w 1624, h 856 LU`，不预设复杂内容组件。
- 章节标题与必要的短说明由内容布局承载，不写入母版固定对象。

章节变化本身不构成更换主导色的理由。背景模式沿用整份 PPT 的策略；不得为了章节装饰而轮换品牌蓝、云灰和墨蓝。

**兼容布局**：单一区域、全幅视觉叠加内容。

### 3.3 内容页母版

**用途标签**：目录、正文、图文、数据、对比、网格、总结等普通内容页。

**固定框架**

- 普通内容页背景默认使用 `#FFFFFF`。
- Logo 固定在右上角，标准与弱品牌变体使用相同锚点和基础尺寸。
- 提供“有标题”和“无标题”两个离散状态，不允许逐页任意拖动标题位置。
- 页码和页脚仅受整份 PPT 级别的开关控制。

**Logo 级别**

| 变体 | Logo 处理 | 使用条件 |
|---|---|---|
| Weak | 将当前品牌官方 Logo 重新着色为 `#C1C7CF` | 普通内容页默认；内容密集、数据、截图和图表页优先 |
| Standard | 浅色背景使用标准版，深色背景使用反白版 | 页面需独立传播、强化品牌归属或承载关键结论 |

- Weak 不是把标准 Logo 降低透明度。不得用任意透明度冒充 `#C1C7CF` 水印版。
- 两个变体不得通过改变位置或大小制造强弱。
- 深色或品牌色内容页属于特殊情况；没有经过验证的深色水印版本时使用 Standard 反白版，不临时发明弱化透明度。

**标题状态**

| 结构布局 | 规则 |
|---|---|
| `Content.WithTitle` | 使用统一页面标题区，`contentArea = x 148, y 240, w 1624, h 728 LU` |
| `Content.NoTitle.TenColumns` | 前 10 栏向上扩展，`contentArea = x 148, y 112, w 1352, h 856 LU` |
| `Content.NoTitle.FullWidth` | 使用完整 12 栏并避让右上角 Logo，`contentArea = x 148, y 240, w 1624, h 728 LU` |

AI 不能仅为了腾空间删除有实际作用的标题。当大数字、结论句或主视觉已经直接承担页面标题功能时，可以选择 No Title。

**兼容布局**：`layouts.md` 中全部六类内容骨架。

## 4. 背景、页码与页脚

### 4.1 背景模式

- 背景是页面视觉属性，不是结构母版或内容区的一部分。布局记录必须分别保存 `structureLayout` 与 `backgroundStyle`。
- 普通内容页默认使用 `#FFFFFF`，只有图片、视频、数据可读性或重点表达确有需要时才切换背景。
- 品牌焦点页和章节过渡页可以使用浅色、深色或品牌色背景，但由整份 PPT 的母版策略统一分配。
- 背景变化必须服务页面职责；不得在相邻普通内容页间交替背景制造装饰节奏。
- 只改变背景不得新增结构布局、改变 `contentArea` 或移动固定对象。若背景导致 Logo 或文字对比度不足，只替换对应前景资产或颜色角色。
- 每页主导色与整份 PPT 的色彩稳定性继续执行 `references/common/design-foundation.md`，母版切换不能成为轮换三种品牌色的理由。

### 4.2 页码与页脚

- 页码和页脚默认关闭。
- 市场传播、销售演示和发布会等短篇 PPT 通常保持关闭；报告、白皮书、培训及较长说明型 PPT 可以在整份文件级别启用。
- 启用后只在普通内容页显示；封面、章节过渡和结束页隐藏。
- 页脚内容完全由用户提供。用户未提供时保持为空，AI 不自行编造版权、保密级别或文档名称。
- 同一份 PPT 的普通内容页不得随机显示或隐藏页码、页脚。

## 5. PptxGenJS 实现

使用真实的 Slide Master，而不是在每页重复绘制固定元素：

```js
pptx.defineSlideMaster({
  title: structureLayout,
  objects: fixedObjects,
  slideNumber,
});

const slide = pptx.addSlide({ masterName: structureLayout });
slide.background = { color: resolvedBackgroundColor };
```

实现约束：

- `structureLayout` 必须来自 `scripts/ppt/layout_qa.mjs` 的结构布局注册表；背景另以 `backgroundStyle` 保存，结构布局名称中不得出现 Blue、Dark、Light 等颜色或明暗词。
- `fixedObjects` 只放 Logo、用户已提供的固定页脚等母版对象，不放具体页面内容。
- 有标题母版可以定义命名明确的 `title` placeholder；无标题母版不保留空标题占位。
- 不创建一个覆盖整页的通用 `body` placeholder 来代替 `layouts.md`。各布局需要不同的一级区域，必须由布局代码计算。
- 页码使用 Slide Master 的 `slideNumber`；关闭页码的母版不定义该属性。
- 每个品牌复用同一套逻辑坐标，只替换当前品牌 Logo 和字体。
- 生成脚本分别保存 `structureLayout`、`backgroundStyle` 和由结构布局返回的 `contentArea`，并写入内部布局验收数据。
- 若渲染器为了切换固定 Logo 的标准版 / 反白版而必须生成技术实现变体，这些变体仍须共享同一个 `structureLayout` 与 `contentArea`；不得被当成新的设计母版，也不得因背景改变几何。
- 修改母版固定框架后重新生成并渲染整份 PPT，不能只检查单页。

## 6. 母版验收

- 是否为整份 PPT 指定了默认内容页母版。
- 普通内容页是否默认使用 `#FFFFFF`，特殊背景是否有功能理由。
- 普通内容页 Logo 是否统一位于右上角，并保持相同基础尺寸。
- Weak 是否实际使用 `#C1C7CF` 重着色版本，而非标准 Logo 降透明度。
- 章节过渡母版是否默认无 Logo；Cover 是否默认显示顶部 Standard Logo；End 是否默认不显示 Logo。
- End 用户要求显示 Logo 且页面仍有主要内容时，是否与 Cover 使用相同 Standard 尺寸和顶部锚点；Logo-only 页面之外是否未使用居中 Focus Logo。
- 品牌焦点页的顶部 Logo、页脚是否排除在主内容组测量之外；主内容组是否在当前结构布局返回的 `contentArea` 内重新测量并垂直居中。
- `BrandFocus.End.NoLogo` 是否使用完整纵向安全区 `y = 112–968 LU`，未继续保留不存在的顶部 Logo 排除区。
- 封面主标题与封底主要结束语是否使用同一 `BrandFocus.Primary` 字号角色；是否存在按页面类型临时缩小封底字号。
- 标题状态是否只使用已注册的 `Content.WithTitle`、`Content.NoTitle.TenColumns` 或 `Content.NoTitle.FullWidth`。
- Logo 排除区、页码和页脚是否未被内容布局覆盖。
- 页码与页脚是否按整份 PPT 统一开关；页脚是否只使用用户提供的内容。
- 背景和 Logo 版本是否保持足够对比度，并符合当前品牌配置。
- `structureLayout` 与 `backgroundStyle` 是否分别记录；是否存在因为背景色不同而新增结构母版或改变内容区。
- 页面是否通过真实 Slide Master 绑定固定框架，而不是逐页复制后产生位置漂移。

先通过 `scripts/ppt/layout_qa.mjs` 的结构与几何硬性验收，再执行 `references/materials/ppt/export-qa.md` 的整份渲染检查；图片目测不能替代内容区和中心偏差计算。
